# 任务模板库

## 使用说明

根据任务类型选择合适的模板，填写具体内容后分配给任务执行 Agent；测试任务分配给质量验证 Agent。

## 1. 标准任务模板

文件：`standard-task.md`

```markdown
# 任务 {T{number}}：{标题}

## 基本信息

- **任务 ID**：T{number}
- **优先级**：{high/medium/low}
- **分配给**：sub-agent-{number}
- **依赖**：{T{number} 或 无}
- **截止日期**：{YYYY-MM-DD}

## 任务描述

{详细描述任务内容和目标}

## 修改范围

### 允许修改

- {文件路径 1}
- {文件路径 2}

### 禁止修改

- {文件路径 1}
- {文件路径 2}

## 验收标准

- [ ] {标准 1}
- [ ] {标准 2}
- [ ] {标准 3}

## 相关资源

- {相关文档或代码链接}

## 备注

{其他需要说明的内容}
```
